☕ Coffee House Dashboard (Power BI)
📊 Project Overview
This project presents an interactive Coffee House Sales Dashboard built using Power BI. The dashboard provides insights into sales performance, customer behaviour, and product trends to support data-driven decision-making.

📂 File Included
https://drive.google.com/file/d/1OKe83eha4GmnxZBM9KpuiibmWBNIbTTK/view?usp=drive_link

🎯 Objectives-

    •	Analyze overall sales performance 
  
    •	Identify top-selling products 
  
    •	Understand customer purchasing patterns
  
    •	Track revenue trends over time 
  
    •	Provide actionable business insights 


  
📌 Key Features-

    •	📈 Sales Analysis – Total revenue, orders, and performance trends 
  
    •	🛍️ Product Insights – Best-selling and least-selling items 
  
    •	🕒 Time-Based Analysis – Daily/Monthly sales trends 
  
    •	👥 Customer Insights – Purchase behavior and patterns
  
    •	📍 Category Breakdown – Sales by product categories 

  
🛠️ Tools & Technologies-

    •	Power BI – Data visualization and dashboard creation 

    •	Data Cleaning & Transformation – Power Query Editor 

    •	DAX – Calculated measures and KPIs



🚀 How to Use-

    1.	Download the .pbix file
     
    3.	Open it using Power BI Desktop
     
    5.	Explore the interactive dashboard visuals


💡 Insights Derived-

    •	Peak sales occur during specific time periods 
    
    •	Certain products contribute significantly to revenue
    
    •	Sales trends help in inventory and staffing decisions
    


📢 Conclusion-
This dashboard helps in understanding business performance and enables better strategic decisions for improving sales and customer experience.
