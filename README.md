☕ Coffee House Dashboard (Power BI)
📊 Project Overview
This project presents an interactive Coffee House Sales Dashboard built using Power BI. The dashboard provides insights into sales performance, customer behaviour, and product trends to support data-driven decision-making.

🎯 Objectives-
  •	Analyze overall sales performance 
  
  •	Identify top-selling products 
  
  •	Understand customer purchasing patterns
  
  •	Track revenue trends over time 
  
  •	Provide actionable business insights 

  
📌 Key Features-

  •	📈 Sales Analysis – Total revenue, orders, and performance trends 
  
  •	🛍️ Product Insights – Best-selling and least-selling items 
  
  •	🕒 Time-Based Analysis – Daily/Monthly sales trends 
  
  •	👥 Customer Insights – Purchase behavior and patterns
  
  •	📍 Category Breakdown – Sales by product categories
